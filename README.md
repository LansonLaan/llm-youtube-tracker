# 🤖 LLM YouTube Landscape Tracker

Automated tool that monitors LLM YouTube channels and generates a table of what creators actually say.

## Live Demo

**https://LansonLaan.github.io/llm-youtube-tracker**

## Features

- 📊 **Structured Table**: Speaker, topics, key points, relationships
- 🎯 **Based on Transcripts**: Uses actual video content, not just titles
- 🌐 **Public Dashboard**: Hosted on GitHub Pages
- 🔄 **Auto-updatable**: Run script anytime to refresh

## Quick Start

```bash
git clone https://github.com/LansonLaan/llm-youtube-tracker.git
cd llm-youtube-tracker
pip install -r requirements.txt
python tracker.py
open index.html
```
